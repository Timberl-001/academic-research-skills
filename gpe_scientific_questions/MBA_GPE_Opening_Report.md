# 硕士研究生学位论文开题报告

**论文题目：** 聚合诱导相分离构筑酰胺骨架/氟化弱溶剂化液相准固态电解质及其高压锂电池应用研究

**体系：** N,N'-亚甲基双丙烯酰胺（MBA）原位聚合 / 1.0 M LiPF₆ + 0.2 M LiDFOB in N,N-二甲基三氟乙酰胺（DMTFA）: 1,1,2,2-四氟乙基-2,2,3,3-四氟丙基醚（TTE）= 1 : 1（v/v）

# 一、开题依据

## 1. 题目来源、形式与内容

**题目来源：** 【国家自然科学基金 / 省部级项目 / 企业合作 / 导师自选课题，项目名称及编号】

**形式：** 实验研究型学位论文（材料制备—机理表征—器件验证）。

**内容概述：** 本课题以高安全、高电压锂电池用准固态电解质为目标，选用双丙烯酰胺类单体 MBA 在氟化弱溶剂化电解液（1.0 M LiPF₆ + 0.2 M LiDFOB / DMTFA : TTE = 1 : 1）中原位聚合。前期实验发现，MBA 体系在该液相中发生聚合诱导相分离（PIPS），形成白色、非均相的"酰胺微颗粒骨架 + 连续液相"结构；与之对照，均相透明的 PEGDA 凝胶电解质性能反而更差。本课题拟围绕这一现象，系统研究：(1) 相分离骨架与 Li⁺ 传输通道的空间解耦机制；(2) 相分离程度的调控规律及其与保液、力学、传输、界面性能的构效关系；(3) 氟化弱溶剂化液相在准固态化后的溶剂化结构保留；(4) 锂盐/氟化溶剂/酰胺骨架三源协同形成的正负极界面膜化学，最终在【高镍三元 NCM811 / 高压钴酸锂 / 其他】‖【锂金属 / 石墨】全电池中验证其高压长循环性能。

## 2. 研究意义

**（1）应用背景。** 高比能锂电池向高电压正极（≥4.4 V）和锂金属负极发展，对电解质同时提出了高氧化稳定性、与负极相容、不燃、不漏液的要求。商用碳酸酯液态电解液氧化窗口不足、易燃、易漏，是制约高安全高比能电池的核心短板之一。

**（2）液态电解液的进展与局限。** 近年来，弱溶剂化电解液、局部高浓电解液（LHCE）、氟化溶剂与双盐成膜策略显著提升了液态电解液的高压耐受性和界面稳定性。然而这些成果绝大多数停留在液态，可燃性与漏液风险依旧存在，且液态电解液与电极间的物理接触在长循环中逐渐退化。

**（3）凝胶/准固态电解质的两大共性瓶颈。** 凝胶聚合物电解质（GPE）被视为液态与全固态之间的折中方案，但传统均相溶胀型 GPE 普遍面临：① **体相传输下降**——聚合物极性基团（尤其聚醚的醚氧）参与 Li⁺ 配位，Li⁺ 由液相自由扩散转为链段辅助跳跃，电导率和迁移数下降，并改变了液相原有的溶剂化结构；② **界面不稳**——凝胶与电极接触、SEI/CEI 的均匀性及其循环中的重构难以兼顾。

**（4）本课题的意义。** 本课题提出以聚合诱导相分离构筑"刚性酰胺骨架 + 连续液相"的空间解耦结构，使聚合物只承担锁液与骨架功能而不进入 Li⁺ 溶剂化鞘，从根本上回避瓶颈①；同时利用氟化弱溶剂化液相与双盐在原位聚合贴合的界面上协同成膜，针对瓶颈②。该工作有望：(a) 为"非均相准固态电解质"提供可控制备方法与构效关系；(b) 将液态弱溶剂化/氟化电解液的高压优势"原汁原味"地移植到准固态体系；(c) 为高安全、高电压锂电池提供一种原位聚合、工艺兼容的电解质方案。

## 3. 国内外研究现状分析

**3.1 凝胶聚合物电解质与原位聚合。** GPE 的制备分为预制多孔膜溶胀法与原位聚合法两类；原位聚合将低黏度前驱液注入电池后热/光引发固化，可充分浸润多孔电极、降低界面阻抗，是近年研究热点[1,2]。常用单体/骨架包括 PEGDA、PEO 衍生物、PVDF-HFP、聚碳酸酯、1,3-二氧戊环（DOL）开环聚合物等[1,2,14]。这些体系大多追求均相透明的凝胶，设计逻辑是"聚合物与液相高度相容"，但相容的代价是聚合物基团参与 Li⁺ 配位、液相被稀释，凝胶化后电导率普遍下降 1 个数量级左右。

**3.2 弱溶剂化、局部高浓与氟化电解液。** Zhang 等提出的 LHCE 以 TTE、BTFE 等弱配位氟醚稀释高浓电解液，在降低黏度的同时保留阴离子富集的溶剂化结构，显著提升锂金属库仑效率和高压稳定性[3,4,15]；Yao 等进一步提出"弱溶剂化电解液"概念，通过削弱溶剂–Li⁺ 作用使阴离子进入溶剂化鞘，形成无机物富集的界面膜[5]。DMTFA 作为 α-氟化酰胺溶剂，兼具高极性（溶盐能力）与弱 Li⁺ 配位（–CF₃ 拉电子），氧化窗口 >5 V，早期作为 Li–O₂ 电池添加剂被证明可在锂金属上生成 LiF 富集 SEI[6]，随后被用于 NCM523 高压添加剂[7]，近期已作为主溶剂用于 NCM91 高压锂金属电池，被认为打破了"极性–配位耦合"[8]。**但上述工作全部为液态体系，DMTFA/TTE 基电解液的凝胶化/准固态化尚未见报道。**

**3.3 双盐与界面成膜。** LiDFOB 兼具氧化与还原活性，可在正极优先氧化、在负极优先还原，生成含 LiF、B–O 物种的无机富集 CEI/SEI，抑制过渡金属溶出并钝化高压正极表面[9,10]；LiDFOB 基双盐电解液在无负极软包电池中实现了致密锂沉积与长循环[11]。在弱溶剂化环境中阴离子更易进入溶剂化鞘，DFOB⁻ 的成膜作用有望被放大，但其在氟化酰胺/氟醚体系及准固态体系中的作用尚不清楚。

**3.4 聚合诱导相分离（PIPS）在电池中的应用。** PIPS 在多孔膜、结构电池电解质领域已有应用：以多官能单体与液态电解液组分一步法制备微孔隔膜[12]，或构建双连续"固–液两相"结构电池电解质并保持低温离子传导[13]。这些工作表明"非均相"结构可同时提供力学骨架与连续液相传输通道。**然而在原位聚合 GPE 领域，相分离与发白通常被视为失败而被回避，尚缺乏将 PIPS 作为主动设计变量、建立"相分离时机—骨架形貌—电化学性能"定量关系的研究；MBA 作为唯一网络单体构筑电解质骨架亦未见报道。**

**3.5 小结与切入点。** 综上，(i) 弱溶剂化/氟化液态电解液成果丰富，但其准固态化是空白；(ii) 均相 GPE 的"聚合物参与配位"瓶颈未被根本解决；(iii) PIPS 在原位聚合电解质中的设计潜力尚未被挖掘；(iv) 双盐在弱溶剂化准固态体系中的成膜机制不清。本课题以 MBA/DMTFA–TTE/LiPF₆–LiDFOB 体系为对象，正是针对上述四个空白。

# 二、研究方案

## 1. 研究目标、研究内容和拟解决的关键问题

### 1.1 研究目标

（1）阐明 MBA 在氟化弱溶剂化液相中聚合诱导相分离的发生条件与骨架形成机制，证明"酰胺骨架—连续液相"空间解耦是其性能优于均相凝胶的根源；
（2）建立"聚合条件 → 相分离时机 → 骨架形貌 → 保液/力学/传输/界面性能"的定量构效关系，确定最优形貌窗口；
（3）证明氟化弱溶剂化液相的溶剂化结构、氧化窗口与脱溶剂化动力学在准固态化后得以保留；
（4）揭示 LiDFOB/氟化溶剂/酰胺骨架三源协同的正负极界面成膜化学；
（5）在【NCM811 / 4.5 V】‖【Li / 石墨】全电池中实现【目标：室温 1C 循环 ≥300 周、容量保持率 ≥80%；自熄、不漏液】（指标按预实验调整）。

### 1.2 研究内容

**内容一：PIPS 型准固态电解质的构筑与骨架形成机制。**
测定 MBA 在 DMTFA、TTE 及其混合溶剂中的溶解度与前驱液状态（真溶液/悬浮）；考察聚合过程中的相分离行为；通过液相抽提获得干骨架，表征颗粒尺寸、连通性、比表面积；与同液相的 PEGDA 均相凝胶（C1）、纯液态（C0）系统对比，建立"相分离 → 解耦"的机理证据链。

**内容二：相分离程度调控与构效关系。**
以 MBA 浓度（如 3/5/8/12 wt%）、DMTFA : TTE 体积比（3:1、1:1、1:3）、聚合温度与引发剂用量为变量，原位跟踪相分离时机（透光率/散射随聚合时间与转化率的关系），统计骨架形貌参数，系统测量保液率、流变屈服应力、离子电导率、Li⁺ 迁移数及界面阻抗演化，绘制"形貌参数—性能"权衡图；通过同成分液态系列扣除液相自身变化，分离形貌效应与溶剂化效应。

**内容三：准固态化前后 Li⁺ 溶剂化结构与传输机制。**
采用 Raman、FTIR、⁷Li/¹⁹F NMR 对比液态与准固态中 PF₆⁻ 的 SSIP/CIP/AGG 分布与 DMTFA 配位状态；PFG-NMR 测定 Li⁺、阴离子自扩散系数；变温 EIS 获得体相与界面活化能；LSV 与恒压浮充评价氧化窗口；结合 MD/DFT 分析酰胺基团是否参与配位及骨架表面 N–H 与阴离子的氢键作用。

**内容四：三源协同界面化学与全电池验证。**
以 C0（液态）、C2（MBA + 碳酸酯液相）、C3（无 LiDFOB）为对照，用 XPS 深度剖析、TOF-SIMS 逐一归因 SEI/CEI 中 B–O、LiF、含 N 物种的来源；Li‖Cu 库仑效率、Li‖Li 长循环与 EIS/DRT 演化评价界面稳定性；TEM/ICP 分析 CEI 厚度与过渡金属溶出；组装全电池进行循环、倍率、高低温与安全（自熄时间、与脱锂正极共存 DSC）测试，并在循环后拆解回溯界面组分。

### 1.3 拟解决的关键问题

（1）**相分离与解耦的因果关系**：如何证明聚合物以独立颗粒相存在、未进入 Li⁺ 溶剂化鞘，而非"液态 + 惰性粉末"的简单叠加？
（2）**相分离的可控性**：TTE 比例同时改变相分离时机与溶剂化结构，如何在实验上分离两种效应？
（3）**非整体骨架的锁液与器件化**：颗粒骨架如何在不自支撑的前提下实现可靠锁液，并以"原位聚合复合隔膜"形式进入电池？
（4）**界面组分的来源归因**：如何用对照实验而非相关性证明 B–O、LiF、含 N 物种分别来自 LiDFOB、氟化溶剂与骨架？

## 2. 研究方法、技术路线、实验方案及可行性分析

### 2.1 研究方法

- **材料制备**：手套箱内配制前驱液（MBA、液态电解液、热引发剂 AIBN 或光引发剂），注入含隔膜/电极的电池后在【60–80 °C】热引发或 UV 固化；液相以 DMC 抽提获得干骨架。
- **结构表征**：偏光显微镜与浊度（前驱液）、原位透光率（相分离时机）、SEM/冷冻断面 SEM/BET（骨架形貌）、FTIR/Raman（转化率、C=C 消失；酰胺 I/II、N–H、C=O 配位）、SAXS（网络尺度）、DSC/TGA（液相 Tg、热稳定）。
- **溶剂化与传输**：Raman 去卷积、⁷Li/¹⁹F/¹¹B NMR、PFG-NMR、变温 EIS（Arrhenius/VTF）、Bruce–Vincent 迁移数、DRT 分峰、LSV 与浮充漏电流、MD/DFT。
- **界面与器件**：XPS 深度剖析、TOF-SIMS、SEM/TEM、ICP-OES、Li‖Cu/Li‖Li/全电池电化学测试、自熄时间与 DSC 安全测试。

### 2.4 可行性分析

（1）**原理可行**：DMTFA 弱配位、高氧化稳定[6–8]，TTE 稀释[3,15]，LiDFOB 双界面成膜[9–11]，PIPS 构筑固–液两相电解质[12,13] 均有独立文献支撑；本课题是其有逻辑的组合与机理深化。
（2）**前期结果支持**：已实现 MBA 体系的原位聚合，并观察到其性能优于同液相 PEGDA 凝胶【补充具体数据：电导率、循环】，为核心假设提供了初步证据。
（3）**条件可行**：所需单体、盐、溶剂均为商品化试剂；课题组具备手套箱、电化学工作站、电池测试系统及常规结构表征条件【详见第三部分】。
（4）**风险与预案**：若 DMTFA 在负极侧还原不稳定，则通过提高 LiDFOB 比例或引入少量 FEC 调控 SEI；若颗粒骨架锁液不足，则以提高 MBA 浓度或改变溶剂比细化骨架，并以隔膜/极片孔隙内原位聚合保证器件化。

## 3. 研究的创新点

（1）**相分离解耦型骨架**：首次利用 MBA 在氟化弱溶剂化液相中的聚合诱导相分离，构筑"刚性酰胺微颗粒骨架 + 连续液相"的非均相准固态电解质，实现聚合物骨架与 Li⁺ 传输通道的空间解耦，从根本上回避均相溶胀型凝胶"聚合物配位 Li⁺ → 电导率/迁移数下降"的共性瓶颈。
（2）**将相分离从缺陷转化为设计变量**：系统建立"聚合条件—相分离时机—骨架形貌—锁液/力学/传输/界面性能"的定量构效关系，为非均相准固态电解质提供可预测的设计方法。
（3）**弱溶剂化液相的准固态"原汁原味"保留**：首次实现 DMTFA/TTE 基高压弱溶剂化电解液的准固态化，并证明其溶剂化结构、氧化窗口与脱溶剂化动力学不因聚合物引入而劣化。
（4）**三源协同双界面及其来源归因**：以对照实验逐一归因 SEI/CEI 中 B–O（LiDFOB）、LiF（氟化溶剂/DFOB⁻）、含 N 物种（酰胺骨架）的来源，并揭示高比表面骨架表面 N–H 对阴离子的界面作用。
