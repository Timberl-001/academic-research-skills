# 给计算同学的需求说明：MBA 相分离骨架是否"锁离子"

## 一句话目标
用 DFT + MD 回答：**在 1.0 M LiPF₆ + 0.2 M LiDFOB / DMTFA:TTE = 1:1 液相中，聚 MBA 骨架的酰胺基团是否进入 Li⁺ 第一溶剂化鞘、是否显著拖慢 Li⁺？** 同时对比 PEGDA（聚醚）骨架作为"会锁离子"的参照。

## 体系信息
- 液相：LiPF₆ 1.0 M、LiDFOB 0.2 M、DMTFA : TTE = 1:1 (v/v)。DMTFA = CF₃C(=O)N(CH₃)₂；TTE = HCF₂CF₂CH₂OCF₂CF₂H。
- 骨架：聚 MBA（MBA = CH₂=CH–C(=O)NH–CH₂–NHC(=O)–CH=CH₂，双键全部聚合后为交联聚丙烯酰胺短桥网络）；对照 PEGDA（Mn ≈ 【575/700】）。
- 实验事实：MBA 体系聚合诱导相分离，聚合物以微米级刚性颗粒存在，液相连续；PEGDA 为均相透明凝胶。聚合物含量约【5】wt%。

## 需要回答的 4 个问题与对应计算

### Q1 单位点配位强弱（DFT，最快，1–2 天）
计算 Li⁺ 与下列配体的结合能（气相 + 隐式溶剂 SMD/PCM，B3LYP-D3/6-311+G(d,p) 或 ωB97X-D，含 BSSE 校正）：
- DMTFA（C=O）、TTE（醚 O / F）、PF₆⁻、DFOB⁻
- 聚 MBA 模型：N-甲基丙酰胺或 N,N'-亚甲基双丙酰胺（饱和化的 MBA 重复单元）的 C=O
- 聚 MBA 自缔合模型：先让两个酰胺形成 N–H···O=C 氢键二聚体，再算 Li⁺ 结合到已氢键化 C=O 上的能量（**关键**：看氢键占用后供体能力下降多少）
- PEGDA 模型：二甘醇二甲醚（单齿 vs 双齿/三齿螯合）
- 另算 N–H 与 PF₆⁻、DFOB⁻ 的氢键能（阴离子锚定可能性）
**交付**：一张结合能柱状图；ESP/NBO 电荷说明 CF₃ 对 DMTFA C=O 的削弱；HOMO/LUMO 用于氧化/还原稳定性排序。

### Q2 液相本身的溶剂化结构（经典 MD，液态基线，3–5 天）
- 盒子：按 1.0 M LiPF₆ + 0.2 M LiDFOB、DMTFA:TTE 1:1 体积比构建（约 100 Li⁺，> 5000 原子），OPLS-AA 或 APPLE&P / 带 0.8 电荷缩放的 OPLS，RESP 电荷；NPT 平衡 ≥10 ns，产出 ≥50 ns。
- 分析：Li–O(DMTFA)、Li–O(TTE)、Li–F(PF₆⁻)、Li–O(DFOB⁻) RDF 与配位数；SSIP/CIP/AGG 比例；Li⁺、PF₆⁻ 自扩散系数 D；DMTFA 在鞘内的驻留时间。
**交付**：溶剂化鞘组成饼图、RDF、D 值，与实验 Raman/⁷Li NMR/PFG 对照。

### Q3 骨架对溶剂化与传输的影响（MD，核心，1–2 周）
两种模型，建议都做：
- **(a) 界面模型（对应相分离）**：构建聚 MBA 交联片段的致密 slab（或球形团簇，直径 3–4 nm，交联度 >80%，酰胺间保留自缔合氢键），置于 Q2 的液相盒子中，形成"颗粒表面/液相"界面。
- **(b) 均相模型（对应 PEGDA）**：PEGDA 链段均匀分散于同一液相中（与实验含量一致）。
- 分析：
  - 距骨架表面 0–0.5 nm、0.5–1 nm、>1 nm 分层的 Li⁺ 溶剂化鞘组成——骨架 O 是否进入第一鞘
  - 骨架 C=O / 醚 O 的 Li⁺ 配位数、Li–O(polymer) 驻留时间 vs Li–O(DMTFA) 驻留时间
  - 分层 D_Li、D_F；体相区 D 是否等于 Q2
  - N–H 与 PF₆⁻/DFOB⁻ 的氢键数与寿命（阴离子是否被吸附）
  - 骨架表面 Li⁺ 密度分布（是否出现表面富集层）
**交付**：分层溶剂化鞘组成对比图（MBA 界面 vs PEGDA 均相 vs 纯液态）、驻留时间表、D 剖面；一句结论："聚 MBA 仅在 <x nm 表面层改变配位，体相与液态一致；PEGDA 全局改变"。

### Q4 为什么会相分离（可选，支撑创新点 2）
- 计算聚 MBA 寡聚物（2–6 聚体）与 DMTFA、TTE、混合溶剂的溶解自由能 / Flory–Huggins χ（MD 或 COSMO-RS）；对比 PEGDA 寡聚物。
- 或 Hansen 溶解度参数估算。
**交付**：χ 或 ΔG_solv 随聚合度和 TTE 比例变化曲线，解释"TTE 越多相分离越早"。

## 优先级
Q1 → Q3(a)+(b) → Q2 → Q4。若只能做一件事，做 **Q3 的分层溶剂化鞘分析**。

## 请计算同学注意
- 聚 MBA 模型必须**交联且刚性**（固定或强约束骨架原子），否则线性聚丙烯酰胺链会像 PEGDA 一样缠绕 Li⁺，结论失真。
- 酰胺自缔合氢键要在初始结构中体现（可先对干骨架做退火）。
- 电荷缩放系数与液相基线保持一致，否则 S 与 C0 不可比。
- 所有结论要有 C0（纯液态）和 PEGDA 两个参照，单独算 MBA 没有说服力。

液相配方与密度、聚合物含量、实验 σ/t_Li⁺/Raman 数据（用于校验 MD），PEGDA 分子量。
